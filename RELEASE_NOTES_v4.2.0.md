# TV-Launcher Min v4.2.0 / Notes de version

## Français
Première version publique proposée de ce fork de CleanYourTV.

**Nouveautés**
- Interface d'accueil et menus en français.
- Six favoris personnalisables depuis la télécommande.
- Déplacement, masquage et réaffichage des applications.
- Menus harmonisés et plus compacts.
- Diagnostic ponctuel de RAM et de stockage.
- Appui long pour accéder aux informations d'une application.

**À savoir**
- Testé par le mainteneur sur Sony Bravia Android TV ; les autres appareils ne sont pas encore validés.
- Les options de sauvegarde/restauration JSON ne sont pas incluses.
- Ne désactivez pas le launcher d'origine avant d'avoir testé l'application.
- Fichier à joindre à cette Release : `tv-launcher.apk` **signé pour la publication**.

## English
First proposed public release of this CleanYourTV fork.

**Highlights**
- French-language UI and menus.
- Six remote-editable favorite apps.
- Reorder, hide and restore grid apps.
- Compact, visually consistent menus.
- On-demand RAM and storage diagnostics.
- Long-press to open Android app information.

**Notes**
- Maintainer-tested on Sony Bravia Android TV; other devices unverified.
- JSON backup/restore is not part of v4.2.
- Keep the original launcher enabled until testing is complete.
- Attach a **release-signed** `tv-launcher.apk` binary.

Upstream: https://github.com/Gathin23/cleanyourtv
